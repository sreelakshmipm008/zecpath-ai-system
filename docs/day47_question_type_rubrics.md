# Day 47 – Question Type Evaluation Rubrics

## Purpose
Define consistent evaluation criteria for conceptual, practical, and scenario-based technical interview questions.

## 1. Conceptual Questions

| Dimension | Evaluation criteria |
|---|---|
| Accuracy | Correct definitions, facts, and distinctions |
| Explanation Depth | Explains how and why the concept works |
| Logical Reasoning | Connects related concepts logically |
| Real-World Application | Provides a relevant use case or example |

## 2. Practical Questions

| Dimension | Evaluation criteria |
|---|---|
| Accuracy | Correct implementation approach and technical details |
| Explanation Depth | Covers important steps and required components |
| Logical Reasoning | Presents steps in a valid, logical sequence |
| Real-World Application | Addresses testing, errors, and practical use |

## 3. Scenario-Based Questions

| Dimension | Evaluation criteria |
|---|---|
| Accuracy | Identifies technically valid causes and solutions |
| Explanation Depth | Explains the situation and proposed solution |
| Logical Reasoning | Shows diagnosis, prioritization, and justification |
| Real-World Application | Considers constraints, risks, and validation |

## Difficulty Expectations

- Basic: Foundational knowledge and straightforward application.
- Intermediate: Connected concepts and independent problem-solving.
- Advanced: Deeper technical judgment, trade-offs, and complex application.

## Common Score Bands

- 0–39: Shallow or mostly incorrect.
- 40–69: Partially correct with limited explanation.
- 70–84: Mostly accurate with clear explanation.
- 85–100: Thorough, accurate, and well-reasoned.

## Assessment Procedure

1. Select the relevant question and its expected answer points.
2. Identify the question type and difficulty.
3. Assess the answer against all four dimensions.
4. Assign a score from 0 to 100 for each dimension.
5. Apply the configured scoring weights.
6. Record assessor notes and explain the result.

Note: These rubrics guide human assessment. They do not independently verify technical correctness.
