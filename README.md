# Zecpath AI System

## Objective
This project is developed as part of the Zecpath AI Internship. The goal is to build an AI-powered recruitment system with a modular and scalable architecture.

## Project Structure

```
zecpath-ai-system/
│
├── data/              # Stores datasets and sample files
├── parsers/           # Resume and document parsing modules
├── ats_engine/        # ATS matching and filtering logic
├── screening_ai/      # AI-based candidate screening
├── interview_ai/      # AI interview assistant
├── scoring/           # Candidate scoring and ranking
├── utils/             # Utility functions (e.g., logger)
├── tests/             # Test scripts
├── logs/              # Log files
├── docs/              # Project documentation
│
├── main.py
├── config.py
├── requirements.txt
├── README.md
└── .gitignore
```

## Technologies Used

- Python
- Git & GitHub
- Virtual Environment (venv)
- Pytest
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Setup

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

```
pip install -r requirements.txt
```

4. Run the project:

```
python main.py
```
